# Video scripts

Three short videos for the WordPress.org listing, the website and YouTube. Each one shows a single task from start to finish, on a fresh store with a common theme (Storefront for the classic checkout, Twenty Twenty-Five for the Checkout block).

Recording tips: 1920×1080, browser zoom 125% so text is readable on a phone, no browser extensions or bookmarks visible, mouse moves slowly. Add captions; many people watch without sound.

## 1. Add your first checkout field (about 60 seconds)

The promise: a new owner adds a field and sees it on the checkout in under two minutes.

| Time | On screen | Voice-over |
| --- | --- | --- |
| 0:00 | The checkout page, plain | "Here's a standard WooCommerce checkout. Let's add a delivery date." |
| 0:05 | WooCommerce > Checkout Fields | "Open WooCommerce, Checkout Fields." |
| 0:10 | Click Additional information, then Add field | "Pick where it goes, then Add field." |
| 0:15 | The type picker; click Date | "Every type has a short description. Choose Date." |
| 0:22 | Type "Delivery date", tick Required | "Give it a label customers understand, and make it required." |
| 0:32 | The preview updates | "The preview is your real checkout, with your theme." |
| 0:40 | Click Publish changes | "Nothing is live until you publish." |
| 0:45 | The checkout in a new tab, the field there | "And there it is, styled like the rest of your checkout." |
| 0:55 | End card: plugin name | "Rachnix Checkout Field Editor. Free on WordPress.org." |
